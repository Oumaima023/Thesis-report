{\textbf{Development of an IOT-based Weather Sensor System for Drone Operations}}\\[-0.5cm]
\noindent\rule{\textwidth}{0.4pt}
{\textbf{Abstract}}


\small
This graduation project presents the integration of the Vaisala PWD12 visibility sensor into an existing weather station originally based on the WXT536 sensor. Deployed on a Revolution Pi controller, the system delivers real-time meteorological data for Unisphere GmbH’s NOVA platform. The hardware ensures robust RS-485 connectivity, while the modular Python software architecture provides dedicated readers and parsers managed by systemd. Local buffering with SQLite guarantees data persistence and reliable synchronization with the AWS AppSync API. The final system is resilient, extensible, and capable of supporting additional sensors with minimal effort.

\textbf{Keywords:} visibility sensor, Vaisala PWD12, weather station, RS-485, Python, offline buffering, AWS AppSync

Ce projet de fin d'études décrit l’intégration du capteur de visibilité Vaisala PWD12 dans une station météo existante initialement basée sur le capteur WXT536. Le stockage local avec SQLite garantit la persistance des données et leur synchronisation fiable avec l’API AWS AppSync. Le système final est résilient, extensible et peut intégrer facilement d’autres capteurs.
